Image management and integrity for microscopy

Rules for acquiring, saving, processing and assembling microscopy images so comparisons are fair and figures are honest.

Draft: not yet reviewed by the author Draft 0.1

Highlighted values are awaiting confirmation. Do not rely on them without checking.

Taking images

  • Use the same settings (bit depth, exposure time, light intensity) for samples that will be compared.
  • Always check for saturation. Do not take saturated images. Check several images across a comparison set when choosing settings. Use 16-bit images if some samples saturate.

Saving images

Save image sets in dated folders that can be matched to pages in your lab notebook.

Processing images

  • Representative cells: do the quantitative analysis first, then choose cells that represent the result.
  • Adjustments: adjust images being compared in exactly the same way.
  • Cropping and figures:
    • Crop from images with the same scaling.
    • Do not change the crop size while assembling the figure; make the figure file larger instead.
    • Use the ROI manager to keep crop sizes consistent.
    • Use white outlines to show where separate images are joined.
    • Include a scale bar.
    • Only after all crops and scale bars are in place, scale the whole figure together (for example in Illustrator).

Keep original, unprocessed files. Raw images for blots follow the same principle: Western blot.
